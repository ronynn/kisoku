A privacy friendly, aesthetically pleasing breathing exercise app to calm the mind. Inspired by the system-24 discord theme aesthetic, and the lessons I learned while designing and improving Karui Todo app.

Features

- 4 breathing exercises like box breathing, 4-2-6-0 breathing.
- Retro terminalesque design: Inspired by Unix customizations found online.
- Lightweight: It's only a 30kb apk.
- Highly customizable: Offers many themes with option for custom fonts.

For more details on features, usage, customizations, discussions, visit the github repo and telegram group.
